# Studio Dudin — Site Design System

Ink and paper only. There is no brand hue: no navy, no red, no accent color of any kind. Emphasis is typographic (italic, weight 500), never a color. If a new element seems to need color, it needs hierarchy instead.

## Color

| Token | Hex | Use |
|---|---|---|
| `--black` | `#000000` | Dark sections, footer, primary buttons |
| `--ink` | `#111111` | Body text, headlines, rules |
| `--paper` | `#FAFAFA` | Page ground |
| `--white` | `#FFFFFF` | Alternating sections, cards, text on black |
| `--muted` | `#55585D` | Secondary text (passes AA on paper) |
| `--gray` | `#8C8F94` | Captions and dividers only — never a paragraph |

Borders are 1px hairlines (`rgba(0,0,0,0.14)` on light, `rgba(255,255,255,0.18)` on dark). No shadows. Photography and screenshots are shown in grayscale and reveal color only on hover.

## Typography

- Headlines: Archivo 800 (h1/h2), 700 (h3), tight tracking.
- Body: Inter 400/500/600, 17px, 1.6 line height.
- Labels, prices, dates, eyebrows: IBM Plex Mono, uppercase, wide-tracked.
- Loaded from Google Fonts in every page `<head>`.

## Logo

- `brand-assets/lockup-signature-ink.svg` / `-paper.svg` — the primary logo: "STUDIO" set in Syne above Valentin's own handwritten "Dudin" signature. Header uses ink, footer uses paper. Scale as one unit; never redraw or reflow.
- `brand-assets/d-mark-ink.svg` / `-paper.svg` — the first "D" of the signature. Used as the large hero motif (bleeding off the right edge on desktop, hidden on phones), as a faint graphic in closing sections, and as a placeholder where a photo is missing.
- `brand-assets/d-mark-tile-dark.svg` / `-light.svg` — the D on a square tile. `images/favicon.svg`, `favicon-32.png` and `apple-touch-icon.png` are made from the dark tile.

## Shape and spacing

Spacing steps: 4 / 8 / 16 / 32 / 64 / 112px. Corners are either pills (buttons, tags) or 3px (cards, frames). Sections alternate paper and white, separated by hairlines; one black section closes each page before the black footer.

## Build

Pages are generated by `build_site.py` (shared header, footer and blocks), so edit the generator and rebuild rather than editing one HTML page by hand. The site is static and hosted on GitHub Pages at studiodudin.com: the contact form composes an email in the visitor's mail app, and retired URLs (about, services, process, notes, clients) are small redirect pages because GitHub Pages ignores `_redirects`.
